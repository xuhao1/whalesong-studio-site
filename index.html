鲸灵工坊Whaleling StudioWhaleling Studio鲸灵工坊

一支 AI 剧组陪你写长篇。你拿主意；总编规划、写手执笔、场记记账、策划推演、导演排戏、后期剪片——让一个故事里的人、世界和许下的承诺，在几十万字里不走样。

A crew of agents for long-form fiction. You decide; the showrunner plans, the writer writes, continuity keeps the record, the planner works out what could happen, the director stages it and post-production cuts it — so that one story's people, world and promises hold across hundreds of thousands of words.

核心想法The idea

一个剧组，而不是一个模型。

A crew, not a model.

擅长规划、调用工具、把大工程理清楚的模型，文笔往往平平；文笔最好的模型，又常常管不好一个工程。鲸灵工坊把活分给一个小班子，各干所长。

Models that are excellent at planning, tool use and keeping a large project straight are often mediocre prose stylists, and the best prose models are often poor project managers. Whaleling Studio hands the work to a small company, each doing what it is good at.

总编ShowrunnerShowrunner总编

你在对话里交谈的 agent · 任意模型

the agent you talk to · any model

听懂你要什么，做规划，决定下一步写哪里，把活派给班底，向你汇报。自己从不写正文。

Understands what you want, plans, decides what is written next, gives the crew its work and reports back. It never writes the prose itself.

写手WriterWriter写手

你为正文挑的模型 · 一次调用

a model you pick for prose · one call

起草、续写、改写正文。拿到的是为它打包好的设定、人物此刻的状态、前情、相关旧段落、线索、章纲和文风。

Drafts, continues and rewrites the manuscript, from a pack built for it: the bible, the cast as they stand, the story so far, earlier passages, the threads, the outline and the style.

Derives outlines and beats, develops characters and the world, explores what-if branches and researches.

Directs audio scripts and storyboards, and plays everyone else when you step into a scene.

后期Post-productionPost-production后期

DSH 的 agent · 有命令行

把配音、音效和分镜画面剪成视频：自己写脚本、跑命令、检查结果，过了检查才交。

Cuts voice, sound and storyboard pictures into a video: writes its own script, runs it and checks the result before handing it in.

场记、策划、导演、后期不是四段提示词，而是跑在 DSH 自己 agent loop 上的四个真正的 agent。每一次运行都是对话的一个子智能体：点开就能看到它查了什么、交回了什么、花了多少。你也可以不经过对话，直接在工坊里操作——每一项能力两边都有。

Continuity, the planner, the director and post-production are not four prompts but four real agents on DSH's own agent loop. Every run is a subagent of the conversation: open it and read what it looked up, what it handed in and what it cost. Or skip the conversation and work in the Studio directly — every operation exists in both places.

写长篇，不丢线

A long book, and the thread kept

每写完一章，场记把它收录成记忆：梗概、硬事实、每个人物章末的状态、线索的进展。每次调用现打一份上下文——前情梗概加上最近几章原文，装得下就是全文——顺着前缀缓存排布。修改都以带差异对比的提案送来，每次采纳都留下原来的版本。

After each chapter, continuity digests it into memory: a summary, hard facts, each character's state at the end, threads moved. Each call gets a context pack built for it — an outline of what came before plus the nearest chapters verbatim, the whole book while it fits — laid out for the prefix cache. Revisions arrive as proposals with a diff, and every applied change keeps the previous version.

人和世界，记得住也看得见

The people and the world, kept and shown

人物卡有结构化的人格、关系、在纸面上的一生（每条剧情线各算各的），还有所有画面都照着画的外貌和声音。查看页里，每个人一页、立绘放大；每个地方是一幅场景，里面的去处和人都标在画上。

Character cards carry a structured persona, relationships, a life on the page (per plot line), and an appearance and a voice that every picture and every line follow. In the viewer, everyone has a page with their portrait large, and every place opens on its picture, with what is in it and who lives there.

走进书里的地方

Step into the places of the book

世界观条目分级、层层嵌套。有设定图的地方就是一幅场景：馆阁、住在里面的人都标在画上，点一下就走进去；拖动滑块，看它在某一章时的样子。

World entries are ranked and nested. Where a place has design art, the picture is a scene: what is in it and who is there are marked on it, each mark a way in; a slider shows it as the story stood at any chapter.

导入写完的书

Bring in a finished book

txt、md、epub、docx：拆章、收录、归并人物、收齐世界观、重建大纲、学会文风，然后接着写。

txt, md, epub, docx: chapters found, digested, cast merged, world collected, outline rebuilt, style learned — then keep going.

五种改法

Five ways to change a book

推演下一步、改一段、改一章、全书改一处、改设定并贯彻到全书——都以提案送来。

Derive what's next, fix a passage, rework a chapter, change something across the book, carry a world change through — all as proposals.

剧情图

The plot graph

故事的其他走向与主线并排，任何一条都能扶正成主线，写过的一个字不丢。

Other ways the story could go sit beside the main line; any can become the main line, nothing written is lost.

有声剧

Audio drama

导演切出旁白、对白、内心独白和环境音；每句合成都"听"一遍，不对就重来。

The director cuts narration, dialogue, inner voice and ambience; every line is measured after it is spoken, and spoken again if it is off.

有声漫与视频

Motion comic and video

分镜跟着有声脚本走；后期 agent 用 ffmpeg 把一章剪成 MP4，检查过才交。

A storyboard tied to the audio script; the post-production agent cuts a chapter into an MP4 with ffmpeg and checks it first.

幕间

Interludes

扮演其中一个人物下场演一场，导演演其他所有人——现生成的视觉小说。

Play one of the characters in a scene while the director plays the rest — a visual novel made on the fly.

手机与网站

Phone and website

同一个 Wi-Fi 下手机扫码就读；也可以把一本书发布成网站。

Phones on the same Wi-Fi read by scanning a code; a book can also be published as a website.

加密的书

Sealed books

正文、设定、记忆、图片、音频，连同关于这本书的对话，在磁盘上都是密文。

Text, bible, memory, pictures, audio and the conversations about the book are ciphertext on disk.

安装Install

三种装法，挑一种。

Three ways in. Pick one.

桌面版

Desktop app

  1. 左侧栏插件 → 添加插件。
  2. 填 github:xuhao1/dsh-novel-writer，或发布包 / 源码目录的绝对路径。
  3. 安装。左侧栏出现鲸灵工坊，新会话的预设里有小说家 Novelist。
  1. Plugins in the left sidebar → Add plugin.
  2. Enter github:xuhao1/dsh-novel-writer, or the absolute path of a tarball or a built checkout.
  3. Install. Whaleling Studio appears in the sidebar and 小说家 Novelist among the presets of a new session.

Web 界面

Web UI

dsh plugin 会调用 pnpm，需要它在 PATH 里。

dsh plugin runs pnpm, which must be on your PATH.

dsh plugin --profile web add \
  github:xuhao1/dsh-novel-writer

自己构建

Build it yourself

需要 Node.js 22+。

Needs Node.js 22+.

git clone https://github.com/xuhao1/dsh-novel-writer.git
cd dsh-novel-writer
npm install   # builds lib/
npm pack      # → .tgz

需要 DeepSeek Harness 0.2.0-rc.2 及以上（< 0.3）。第一次打开工坊，选一个服务、贴一个 key，插图、配音和检索就一次配好；文字模型用 DSH 里已经接好的。ChatGPT 订阅也能画图，不用 key。

Requires DeepSeek Harness 0.2.0-rc.2 or later (< 0.3). The first time the Studio opens, pick a service and paste one key: pictures, speech and retrieval are set up at once; text runs on whatever models DSH already has. A ChatGPT subscription can draw too, with no key.

开源Open source

书是你的，代码也是开放的。

The books are yours. The code is open.

以 LGPL-3.0-or-later 发布。书就是你工作区里的普通目录——Markdown 和 JSON，放进 git 也顺手。除了你配置的模型接口，不往任何地方发数据，没有遥测；密钥只存在本机 DSH 的凭据库里。

Released under the LGPL-3.0-or-later. A book is an ordinary directory in your workspace — Markdown and JSON that version well with git. Nothing is sent anywhere but the model endpoints you configured; there is no telemetry, and keys stay in DSH's credential store on your machine.
